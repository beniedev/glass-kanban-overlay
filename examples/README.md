# Examples

These Markdown files are public-safe sample boards for testing Glass Kanban Overlay without using a private vault.

Use them by adding the file manually in **Settings** and selecting one of its `##` columns. The app only reads or writes files you explicitly add.

Notes:

- The sample file names avoid `archive`, `backup`, and similar path tokens because the app blocks those paths by design.
- `## Archive` inside a Markdown file is fine when it follows the Obsidian Kanban `***` separator.
- Example paths are not wired into `Data/config.sample.json` because real users need local absolute paths.
